## 再開と検証

既存チェックアウト `/workspace/first` を使う。追加の作業ツリーは不要。

```bash
cd /workspace/first
npm test
npm run build
npm start
```

依存する実行環境はPython 3とNode.js。通常のサイト実行にはnpmパッケージ追加は不要。`npm start` はポート3000でサイトを配信する。ダウンロード版は `site/standalone.html` を開く。
