# SEMI ATLAS — 半導体バリューチェーン

9工程・42社の工程マップと企業詳細を表示する静的Webアプリです。前工程から後工程を左から右へ配置し、装置・部品・材料メーカーを分類します。企業詳細には財務構成比、製品シェア比較、確認済み適時開示、公式IR資料リンク、関連ニュースを表示します。

## 自動取得と公開

`.github/workflows/daily.yml` をリポジトリの既定ブランチ `main` に配置すると、GitHub Actions が毎日22:00 UTC（翌日07:00日本時間）に情報を取得し、GitHub Pagesに配信します。時刻は予定でありGitHub側の混雑によって遅れることがあります。手動実行にも対応しています。

導入手順：

1. この変更を `main` に取り込みます。
2. GitHubリポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
3. **Actions → Daily data update and Pages → Run workflow** を実行します。
4. 成功した実行の `deploy` ジョブまたは Settings → Pages に表示される公開URLを開きます。現在のローカル作成だけではWebサイトは公開されません。

日次更新はAPIキーや有料ニュース契約を使いません。GitHub ActionsとPagesの無料利用範囲はリポジトリの公開設定・利用プラン・利用量によります。Pagesはアプリを公開するため、非公開情報をJSONに登録しないでください。

取得結果は `site/data/updates.json` に保存し、Actionsのボットが `main` にコミットします。`contents: write` が必要です。ブランチ保護や組織ポリシーでボットによる更新が拒否される場合は、更新方法の調整が必要です。取得失敗を成功扱いせず、画面に状態と最後の成功日時を表示します。全ニュース取得失敗時も前回の情報を保持して配信し、Actionsに警告を残します。コード・ビルド・保存が失敗した場合は公開しません。

## 無料の取得元と範囲

- ニュース：Google NewsのRSS検索。企業名・別名と半導体関連語で検索し、見出しでも企業名と関連語を検証します。直近90日・1社最大12件。見出し・媒体名・日時・リンクだけを保存します。本文の転載、有料記事の本文取得は行いません。リンク先に有料記事が含まれることがあります。Google Newsは無保証のRSSで、形式変更や停止により取得できない場合があります。利用条件は取得元のものに従ってください。
- 公式IR資料：最初は東京エレクトロン、ASML、ニコン、SCREEN、ディスコ、SUMCO、信越化学、レゾナックの8社の公式IR URLを設定しています。各URLのライブ取得はこのクラウドの接続制限により未検証です。公開HTMLから決算等のPDF・日付入り資料リンクを抽出し、同一ホストのIR一覧を最大1ページ追加取得します。JavaScriptのみのサイトや異なるサブドメインの資料は収集できない場合があります。残り34社は公式IR取得元未設定と表示します。
- 適時開示：公式IRの自動収集結果を、正式な適時開示と誤認させないように分けます。正式な適時開示と確認できた資料は `research.json` の `disclosures` に出典付きで登録します。TDnet全件自動取得は未実装です。
- 財務比率：決算資料リンクの発見は自動化しますが、部門数値の抽出・検証は自動反映しません。同じ期間・通貨・会計基準の確認済み数値だけを登録します。未確認と非開示を区別し、全社利益ゼロや赤字時に誤解を招く割合を表示しません。
- 製品シェア：出典のある確認済みデータだけ表示します。同じ製品市場・年・地域・金額／台数の定義を1つの比較にまとめます。有料調査資料の取得・転載は行いません。初期版に確認済みシェア数値はありません。

ニュースの関連性は見出しによる自動判定です。同名企業や引用による誤検出、見出しに製品名がない記事の取りこぼしがあり得ます。確認が必要な情報を判断の根拠とする場合は原文を参照してください。

## 手元で開く

Python 3.12以上・Node.jsが利用できる環境で、依存パッケージのインストールは不要です。

```sh
npm test
npm run build
npm start
```

開発サーバーはポート3000です。

**`site/standalone.html` はダブルクリックで開ける単一HTML版です。** 生成時点のデータを内包しており、ネット接続やサーバーなしで閲覧できます。最新データへの自動更新はGitHub Pages版で行います。Actions実行結果の **Artifacts → semi-atlas-offline** からHTMLのZIPをダウンロードすることもできます。Artifactsの取得にはGitHubログインが必要な場合があります。

```sh
npm run update     # 無料RSS・登録済み公式IRを取得
npm run check      # データの出典・比率・市場構成を検証
npm run build      # 配信用HTMLと単一HTMLを生成
```

収集処理はPython標準ライブラリのみで動作し、TLS検証と既存のプロキシ設定を保持します。四並列・1リクエスト15秒・最大2MB。HTMLの見出しとリンクのみに限定しています。

## データ管理

- `site/data/catalog.json`：企業・別名・製品・工程・公式サイト・IR URL。初期の製品分類は要確認です。複数分野を扱う企業の分類は主な表示区分を示します。
- `site/data/research.json`：確認済みの財務値・市場シェア・適時開示。
- `site/data/updates.json`：自動取得された見出し・IR資料リンク・取得状態。
- `sources.json`：取得のON/OFF、件数、期間、タイムアウト。

入力例は `docs/data-format.md` を参照してください。市場シェアと財務値は検証処理で出典・期間等を必須にします。定義が違う部門利益を営業利益として登録しないでください。セグメントに非半導体事業が含まれる場合、その全額を半導体事業の値と扱わないでください。初期版では確認済み財務値は未登録です。

公開版は閲覧用です。ブラウザーからの登録・サーバー管理画面・認証はありません。データ編集はGitHub上のJSON編集とコミットで行います。

## この環境での検証制限

Google Newsと公式IRのホストは現在のクラウドネットワークで許可されていません。環境設定の下書きに必要なドメインを追加しましたが、下書き保存だけではランタイムへ反映されません。設定を反映した後に `npm run update` でライブ取得を検証してください。GitHub Actionsはこのクラウドのネットワーク制限とは別の実行環境です。

このタスクでは公開されたWebサイトや稼働中の日次スケジュールの成功を意味しません。公開はGitHubへの反映・Pages設定・Actionsの成功確認後に成立します。
